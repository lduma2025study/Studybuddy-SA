# Studybuddy

A study companion app to help students study smarter, stay organised, and stay motivated.

## ✨ Features
- Create and organise study notes
- Plan study sessions with a timetable
- Track progress and stay on top of deadlines
- Simple, mobile-friendly design

## 🛠️ Built With
- HTML, CSS, JavaScript
- GitHub Pages

## 🚀 How to Use
1. Open the project
2. Explore your notes and timetable
3. Start studying!
